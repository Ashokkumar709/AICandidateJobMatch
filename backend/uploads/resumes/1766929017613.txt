uses in routing:(CN)
1️⃣ IP Address (Network Layer)
Used by routers to decide the path from source to destination across networks.
Every router on the path checks the destination IP address in the packet header to forward it to the next hop.
Example: A packet going from your laptop (192.168.1.5) to Google (142.250.190.78).
Routers along the way keep looking at 142.250.190.78 (destination IP).
They decide the next hop based on their routing table.
✅ So, IP address is the key for routing.
2️⃣ MAC Address (Data Link Layer)
Only works inside a local network (LAN).
When your computer sends a packet to the router, it uses the router’s MAC address (next hop).
Once the packet leaves your LAN, the MAC address is changed hop-by-hop.
Routers rewrite the frame with new MAC addresses for each link, but the IP address stays the same end-to-end.
✅ So, MAC address is for local delivery, IP address is for global routing.

🌐 HTTP (HyperText Transfer Protocol)
Type: Request–Response protocol.
Communication: One-way at a time. Client always initiates (browser → server).
Connection: Each request opens a new TCP connection (unless using keep-alive).
Latency: Higher (because every interaction needs headers + handshake).
Use Cases: Websites, APIs, file downloads, form submissions.
🔌 WebSocket
Type: Full-duplex protocol (two-way).
Communication: Both client and server can send data anytime.
Connection: Single persistent TCP connection (after initial HTTP handshake).
Latency: Very low (no repeated headers or handshakes).
Use Cases: Chat apps, gaming, stock tickers, live notifications, collaborative apps.

Here are the different types of the JOINs in SQL:

(INNER) JOIN: Returns records that have matching values in both tables
LEFT (OUTER) JOIN: Returns all records from the left table, and the matched records from the right table
RIGHT (OUTER) JOIN: Returns all records from the right table, and the matched records from the left table
FULL (OUTER) JOIN: Returns all records when there is a match in either left or right table

call by reference
#include <iostream>
using namespace std;

void modifyReference(int &x) { // reference parameter
    x = x + 10;
    cout << "Inside function (call by reference): " << x << endl;
}

int main() {
    int a = 5;
    cout << "Before function call: " << a << endl;
    modifyReference(a);
    cout << "After function call: " << a << endl; // value changed
    return 0;
}
